Expected columns

The first row is treated as a header and skipped. Students are matched on the student ID in the first column — an ID already on file is updated, a new one is added. Nothing is ever deleted by an import.

  1. Student ID (required)
  2. ignored
  3. First name (required)
  4. Last name (required)
  5. Status (single character)
  6. AC box
  7. Classification (FR / SO / JR / SR / OTHER)
  8. ignored
  9. AC email (required)

An unrecognised classification is recorded as OTHER rather than failing the row. Rows that cannot be imported are listed after the upload with the reason, and the rest still import.
